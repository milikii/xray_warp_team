# Xray-core v26.9.9 (2026-09-09 snapshot)

> Source: https://github.com/XTLS/Xray-core/releases/tag/v26.9.9
> Knowledge base synced at: 2026-09-09

## Highlights

- Latest **pre-release** covered by this knowledge base; the latest **stable** release is v26.3.27 (all releases from v26.4.13 through v26.9.9 are pre-releases).
- Continued refinement of XHTTP (SplitHTTP) transport and REALITY security layer.
- Empty `xmux` block now defaults to `maxConnections: 3`, `hMaxRequestTimes: 600-900`, `hMaxReusableSecs: 1800-3000` (source/config/transport_method.go:451-458).

## Known Field Changes Since v25.x

| Field | Change | Version | Notes |
|-------|--------|---------|-------|
| `decryption` (VLESS) | Extended | v26.x | Now supports `mlkem768x25519plus.*` experimental prefix. |
| `mldsa65Seed` / `mldsa65Verify` | Added | v26.x | ML-DSA-65 support in REALITY. |
| `allowInsecure` (TLS) | Deprecated | docs/stable/config/transports/tls.md:91-100 | Still parsed (source/config/transport_security.go still has the field); official docs recommend `pinnedPeerCertSha256` / `verifyPeerCertByName` instead. |
| `password` (REALITY client) | Renamed | v25.x+ | `publicKey` is the old name, `password` is the current name; the two are aliases (docs/stable/config/transports/reality.md:195-197). |
| `target` (REALITY server) | Renamed | v25.x+ | `dest` is the old name, `target` is the current name; the two are aliases (docs/stable/config/transports/reality.md:74-78, source/config/transport_security.go:30-31). |

## Transport: XHTTP (SplitHTTP)

- `mode` default: `"auto"` (source/config/transport_method.go:320).
- `xPaddingBytes` cannot be disabled (From/To must be >0 if set) (source/config/transport_method.go:334).
- `xPaddingKey` defaults to `"x_padding"` (source/config/transport_method.go:338).
- `headers` must not contain `"host"` (case-insensitive) (source/config/transport_method.go:673).
- `extra` field supported for advanced overrides.

## Security: REALITY

- Server-side: `dest`, `serverNames`, `privateKey`, `shortIds` are mandatory.
- Client-side: `fingerprint`, `publicKey` (or `password`) are mandatory.
- `minClientVer` / `maxClientVer` enforce client version range.
- REALITY targets whose SNI ends in `.ru` / `.ir` / `.cn` or contains `apple` / `icloud` / `microsoft` trigger a warning in the config layer (source/config/transport_security.go:165-166).

## Security: TLS

- `allowInsecure` deprecated (still parsed). Official recommendation: `pinnedPeerCertSha256` or `verifyPeerCertByName` (docs/stable/config/transports/tls.md:91-100).
- `ECH` (Encrypted Client Hello) fields added: `echServerKeys`, `echConfigList`, `echSockopt`.

## Deprecations

| Feature | Status | Replacement |
|---------|--------|-------------|
| `allowInsecure` | Deprecated | `pinnedPeerCertSha256`, `verifyPeerCertByName` |
| REALITY `dest` | Old name | `target` (current name; aliases of each other) |
| REALITY `publicKey` | Old name | `password` (current name; aliases of each other) |

## Gaps in This Snapshot

- Full protobuf default mapping for all transports not yet completed.
- Hysteria2, WireGuard, TUN parameter YAMLs not yet extracted.
- mKCP / QUIC considered legacy; low priority unless requested.
