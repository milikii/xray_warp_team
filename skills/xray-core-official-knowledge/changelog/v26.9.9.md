# Xray-core v26.9.9 (2025-09-09 snapshot)

> Source: https://github.com/XTLS/Xray-core/releases/tag/v26.9.9
> Knowledge base synced at: 2025-09-09

## Highlights

- Latest stable release covered by this knowledge base.
- Continued refinement of XHTTP (SplitHTTP) transport and REALITY security layer.

## Known Field Changes Since v25.x

| Field | Change | Version | Notes |
|-------|--------|---------|-------|
| `decryption` (VLESS) | Extended | v26.x | Now supports `mlkem768x25519plus.*` experimental prefix. |
| `mldsa65Seed` / `mldsa65Verify` | Added | v26.x | ML-DSA-65 support in REALITY. |
| `allowInsecure` (TLS) | Removed | v25.x+ | Setting to `true` now errors. Use `pinnedPeerCertSha256` or `verifyPeerCertByName`. |
| `password` (REALITY client) | Renamed | v25.x+ | Use `publicKey` instead. `password` is still accepted as alias. |
| `target` (REALITY server) | Renamed | v25.x+ | Use `dest` instead. `target` is still accepted as alias. |
| `spiderX` default | Changed | v25.x+ | Defaults to `/` if empty. |

## Transport: XHTTP (SplitHTTP)

- `mode` default: `"auto"`.
- `xPaddingBytes` cannot be disabled (From/To must be >0 if set).
- `xPaddingKey` defaults to `"x_padding"`.
- `headers` must not contain `"host"` (case-insensitive).
- `extra` field supported for advanced overrides.

## Security: REALITY

- Server-side: `dest`, `serverNames`, `privateKey`, `shortIds` are mandatory.
- Client-side: `fingerprint`, `publicKey` (or `password`) are mandatory.
- `minClientVer` / `maxClientVer` enforce client version range.
- Domain warnings present for `.ru`, `.ir`, `.cn`, `apple`, `icloud`, `microsoft`.

## Security: TLS

- `allowInsecure` removed. Use certificate pinning or name verification.
- `ECH` (Encrypted Client Hello) fields added: `echServerKeys`, `echConfigList`, `echSockopt`.

## Deprecations

| Feature | Status | Replacement |
|---------|--------|-------------|
| `allowInsecure` | Removed | `pinnedPeerCertSha256`, `verifyPeerCertByName` |
| REALITY `target` | Deprecated alias | `dest` |
| REALITY `password` | Deprecated alias | `publicKey` |

## Gaps in This Snapshot

- Full protobuf default mapping for all transports not yet completed.
- Hysteria2, WireGuard, TUN parameter YAMLs not yet extracted.
- mKCP / QUIC considered legacy; low priority unless requested.
